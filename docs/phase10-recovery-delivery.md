# 恢复机制、检索与测试收尾

`v2026.11.11`：247 条登记知识，其中 60 条原版机制研究。

- 新增计时器重放、实体引用重接与奖励队列恢复研究，帮助 AI 判断读档后的重复任务、旧监听和重复奖励问题。
- 改进 API 与多步骤检索，让有限预算优先容纳完整合同和解决当前问题所需的步骤；详细来源核验可继续展开。
- 测试结束后自动清理临时 Mod，日志与复现快照保留在测试输出目录；调试时可显式保留副本，异常遗留可按清单补清。
- 完善直接注册、模块拆分、失败恢复和优化验收的选择依据，帮助 AI 减少多余封装并保留必要的联机、生命周期判断。
