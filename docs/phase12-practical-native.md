# UI、生物 AI、农作与船体开发

`v2026.11.12.1`：279 条登记知识，其中 92 条机制研究。本轮新增 12 条研究、34 项 API 合同。

本轮补充四类常用开发场景，让 AI 更容易找到适合需求的原版入口，并判断何时采用更简单的自有实现。

| 新增内容 | 用途 |
|---|---|
| [界面与输入](../references/ui-screen-input.md) | 接入弹窗、焦点和本地 HUD，处理按键消费与关闭 |
| [生物 AI](../references/creature-ai-practical.md) | 配置索敌、追击与逃跑，分清坐标返航和真正入巢 |
| [农田与作物](../references/farming-crops.md) | 接入水肥、照料、压力与收获，按玩法选择完整农作物或普通植物 |
| [平台与船体](../references/boats-platforms.md) | 制作船上装置，复用船体推力、帆力和制动入口 |

Skill 强化独立工程判断：确认原版实际行为与接入约定，再选择实现结构；按实际收益评价简化和优化。检索补充背包、堆叠、跟随与骑乘等常用问法，更容易找到拆堆实体、数量和归属等关键机制。
