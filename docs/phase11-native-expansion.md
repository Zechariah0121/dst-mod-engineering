# 原版机制与 API 大拓展

`v2026.11.12`：267 条登记知识，其中 80 条原版机制研究。本轮新增 20 条研究、96 项 API 合同。

| 新增方向 | 帮助 AI 解决的问题 |
|---|---|
| 战斗与伤害 | 分清护甲吸收、耐久、抵挡、反伤和条件减伤的结算顺序 |
| 物品与装备 | 处理转移、拆堆、并堆、剩余物和装备替换时的对象归属 |
| 制作与采集 | 追踪材料消费、产物初始化、工具磨损和工作完成回调 |
| 移动与生物关系 | 正确接入多来源移速、预测、跟随关系及上下坐骑 |
| 世界与分片 | 理解逐字段状态通知、Shard RPC 与迁移抵达流程 |

跨主题检索优先交付互补的完整知识原子，剩余内容提供可直接继续读取的参数，减少小预算下只命中单个主题的问题。
