# 有期限效果与技能资源 HUD

本轮提供两个可以单独安装的最小 Mod。它们分别处理世界实体上的有期限效果，以及玩家资源的服务器结算和本地显示。示例数值用于验证接线，接入其他项目时按目标功能设置。

| 功能 | 示例覆盖 |
|---|---|
| [有期限效果](../references/chain-timed-effect.md) | 来源装置和目标之间的倍率应用、重复施加、取消、目标丢失、存档恢复与到期撤销 |
| [技能资源与 HUD](../references/chain-skill-resource-hud.md) | 普通背包格右键、执行帧校验与扣费、定向状态同步、初始 HUD 和实例重建 |

先从对应指南找到入口和适用范围，再按需要读取 `EXP-CHAIN-EFFECT-001` 或 `EXP-CHAIN-SKILL-HUD-001`。两个条目均按研究材料登记。指南单列自写示例的实际游戏验证。

```text
python -B -X utf8 run_kb.py review EXP-CHAIN-EFFECT-001
python -B -X utf8 run_kb.py review EXP-CHAIN-SKILL-HUD-001
```

## 验证结果

有期限效果示例通过了同一隔离存档的两次独立专服启动。第二个进程读回目标和剩余时间，实际 `Combat:CalcDamage` 消费恢复后的倍率。缺失目标进入清理路径，随后一次原版 Timer 到期撤销对应倍率。

技能资源示例通过了实际服务端背包动作、执行帧扣费及取消、余额不足、重复执行和物品失去归属检查。另一个专服进程从世界存档恢复了测试宿主的资源值。HUD 首次读取、dirty、幽灵状态和重建通过 Lua 替身。真实客户端输入、网络送达与画面、真人重连和跨分片留待游戏验收。
